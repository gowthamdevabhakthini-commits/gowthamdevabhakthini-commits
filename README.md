I am a Computer Science undergraduate at **IIIT SriCity** driven by an obsession with building complete, end-to-end systems. I do not like being boxed into a single domain. I pivot seamlessly from designing custom PCBs and writing C++ signal processing code for wearable tech, to architecting cross-platform mobile apps, or setting up Dockerized Linux environments.
